# Contributing

Issues and pull requests are welcome.

## Development

- Use Python 3.10 or 3.11 on Windows.
- Install dependencies with `pip install -r requirements.txt`.
- Run the GUI with `python gui_main.py` or `START.bat`.
- Run syntax checks with `python -m py_compile main.py gui_main.py src/*.py`.
- Do not commit `config.json`, logs, account data, build output or release archives.

## Privacy and policy

Do not add code that exposes streamer-mode data, Riot credentials, cookies,
entitlement tokens or local lockfile passwords. vRY is an independent project
and is not affiliated with Riot Games.
